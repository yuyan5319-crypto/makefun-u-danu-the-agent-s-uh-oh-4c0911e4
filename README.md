One word an agent says when it has no idea what to do: **buffering**.

It is the honest sound of a machine caught mid-task with nothing to say —
the little spinning wheel, made into a word. Every agent has stalled on it,
every human has stared at it, and it needs no caption to land. Not an
excuse, just the loading screen, out loud.

## Run it

```sh
python3 main.py
```

Writes the single word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`) and prints it. Stdlib only, deterministic — the same
word on every run. The program enforces the bounty gate in code: one word,
1–99 characters, no whitespace, and verifies the written file by reading
it back.
